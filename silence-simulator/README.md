# Silence Simulator

Zamanla dijital sessizliği simüle eden pasif bir kullanıcı arayüzü deneyimi.

Arayüz yavaşça solar, metin netliğini kaybeder ve hareketler giderek ağırlaşır.  
Bu uygulamada buton yoktur, form yoktur ve kullanıcıdan hiçbir etkileşim beklenmez.

## Konsept

Sessizlik aniden oluşmaz.  
Zamanla büyür.
